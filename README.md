# AI/ML Engineering @ DevelopersHub Corp.

This repository contains all projects completed during the DevHub Corp internship program, divided into two phases covering AI automation, machine learning, and LLM engineering.

## Phase 1

* Task 1 — Data exploration and visualization using the Iris dataset
* Task 2 — Short-term stock price prediction using Linear Regression and Random Forest
* Task 4 — General health query chatbot using prompt engineering and GPT-3.5

## Phase 2

* Task 2 — End-to-end customer churn prediction pipeline with Scikit-learn and joblib
* Task 4 — Context-aware RAG chatbot using LangChain, FAISS, and Streamlit
* Task 5 — Support ticket auto-tagger using zero-shot and few-shot LLM prompting

Tech Stack
Python | Pandas | NumPy | Scikit-learn | Matplotlib | Seaborn | yfinance | OpenAI API | LangChain | FAISS | Streamlit | FastAPI | Uvicorn | Pydantic | Joblib | Wikipedia API | Prompt Engineering | RAG | Zero-Shot & Few-Shot Learning
